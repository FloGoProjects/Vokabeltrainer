# Vokabel-Gold

Vokabeltrainer (Web-App) fürs iPad: Karteikasten, Antworten eintippen, Vokabel-Gold als Belohnung, drei Skins.

- App: https://flogoprojects.github.io/Vokabeltrainer/
- Entwicklung: `npm install`, `npm test`, `npm run serve` → http://localhost:8080
- Neue Unit: `data/en/unit-XX.json` anlegen, in `data/index.json` eintragen, `npm run check-vocab`

Details: `CLAUDE.md`, Anforderungen: `requirements.json`.
